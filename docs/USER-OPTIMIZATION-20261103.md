# 用户体验优化与验收

基线：`codex/wechat-channels` / `a0388886815bedbd89854ae0614d189a3d208bb8` / 0.7.0。
目标：首次准备、读取、下载、恢复、批量和长期管理形成可理解且可恢复的完整流程。
实施目录：当前仓库；证据：`evidence/user-optimization-20261103/`。

## 验证约定

开发期使用受影响的测试；公共契约变更后执行 typecheck、lint、单元与真实媒体测试；稳定集成点执行构建、Electron 用户旅程与三尺寸布局。基线证据按输入适用性复用。每条记录包含命令、退出码、输入指纹、日志和覆盖条件。用户媒体与登录在隔离测试之外保留。

# 拾片使用指南

适用版本：**0.6.1**。更新日期：2026-10-27。

拾片把视频链接保存为本地视频或音频。本文按实际操作介绍单条下载、批量添加、任务队列、历史、偏好和访问恢复。

[返回项目首页](../README.md)

## 首次打开

1. 从 [0.6.1 发布页](https://github.com/Z3FisherX/clipkeep/releases/tag/v0.6.1) 下载并解压 App；进入 `拾片-darwin-arm64` 文件夹，将 `拾片.app` 拖入“应用程序”并打开。源码构建产物位于 `release/拾片-darwin-arm64/拾片.app`。
2. 点击窗口底部的 **设置与帮助**，查看工具状态。
3. 确认 yt-dlp、FFmpeg、ffprobe 和 Node 均已就绪。
4. 点击 **更换目录**，选择视频与音频的保存位置。

当前应用包面向 Apple Silicon Mac，声明最低系统版本为 macOS 13.0，采用本地 ad-hoc 签名。macOS 出现来源确认提示时，核对应用来源后使用系统提供的打开入口。

App 随附 yt-dlp，其余工具使用本机安装。工具检测会查找 `/opt/homebrew/bin`、`/usr/local/bin`、`~/.local/bin`、`/usr/bin`；Node 还会检测 fnm 的安装目录。准备好工具后，点击 **重新检测**。

## 保存一条视频或音频

1. 在 **视频链接** 中粘贴链接，或粘贴包含一个链接的分享文案。
2. 点击 **读取视频**，也可以在输入框中按回车。
3. 核对显示的标题、平台和时长；出现 **帖子视频** 时，选择需要保存的条目。
4. 选择保存格式和清晰度，确认保存位置。
5. 点击 **开始下载**。
6. 完成后进入 **历史**，点击 **打开视频**、**打开音频** 或 **打开文件夹**。

### 选择保存格式

| 选项 | 保存结果 | 适合的用途 |
| --- | --- | --- |
| 带声视频 | MP4 视频 | 离线观看、整理视频素材 |
| 纯音频 | M4A 音频 | 收听访谈、讲座或其他音频内容 |
| 视频 + 音频 | MP4 与 M4A 各一份 | 同时保留画面和可独立播放的音频 |

静音来源显示 **视频**，可选输出随来源的画面与音轨信息调整。视频与音频双输出会复用下载成果。

### 选择画质

**默认清晰度** 决定新读取内容的自动选择：

| 策略 | 自动选择规则 |
| --- | --- |
| 最高可用 | 在已知尺寸的可用档位中选择最高画质 |
| 最高 1080p | 选择 1080p 以内的最高可用档位 |
| 最高 720p | 选择 720p 以内的最高可用档位 |

竖屏视频按短边判断，例如 1080 × 1920 按 1080p 策略选择。当前视频也可以通过 **清晰度** 单独指定档位。

来源提供 **原始画质** 时，选择该档位并勾选 **确认使用原始画质，尺寸以成品为准**。完成后，历史记录会展示实际尺寸。需要手动选择档位时，清晰度列表显示 **选择清晰度**。

## 使用任务队列

### 加入队列与开始下载

| 按钮 | 作用 |
| --- | --- |
| 加入队列 | 将当前内容加入等待列表；队列正在执行时，按顺序处理新任务 |
| 开始下载 | 将当前内容加入队列，并开始按队列顺序处理 |
| 继续队列 | 启动等待任务，或继续暂停、重启后的队列 |
| 当前任务完成后暂停 | 让当前任务处理完成，后续任务等待用户继续 |
| 取消任务 | 结束当前任务的执行，保留已生成的文件；运行中的队列继续处理后续任务 |
| 取消读取 | 结束当前链接的信息读取，下载任务独立运行 |

队列一次下载一个任务。下载期间，可以继续粘贴链接、读取内容并加入队列。

### 排序和编辑等待任务

在右侧 **下载中** 页签找到任务，展开 **更多操作** 可整理队列：

- **上移 / 下移 / 移到队首**：调整任务顺序，当前执行的任务继续处理。
- **编辑设置**：修改该任务的输出类型与清晰度策略，再点击 **保存任务设置**。
- **使用当前保存目录**：为尚待创建文件的任务应用主窗口当前选择的目录。
- **移除任务**：移除任务记录，已经生成的本地文件继续保留。

单条任务的编辑作用于该任务。已确认的原始画质任务在编辑时继续保留原始档位，成品尺寸以实际为准。创建过文件的任务继续沿用原任务目录；需要换位置重新保存时，可通过 **重新下载** 创建新任务。

### 重复内容提示

同一内容已在队列或历史中时，拾片会显示重复提示。可以在对应列表查找已有任务；需要另存一份时，点击 **仍然添加**。队列处于暂停状态时，点击 **继续队列** 启动处理。

## 批量添加

1. 点击左侧顶部的 **批量添加**。
2. 粘贴多条视频链接或分享文案，推荐每条占一行。
3. 点击 **读取列表**，等待逐条显示读取结果。
4. 为各条内容选择输出类型、清晰度，以及需要的帖子视频条目。
5. 原始画质来源勾选 **使用原始画质**。
6. 点击 **加入 N 个任务**，将已准备好的内容加入队列。
7. 队列处于暂停状态时，点击 **继续队列**。

每批最多 50 个链接，分享文案总量最多 64 KiB；完全相同的链接会先合并。按钮中的数量表示当前已满足保存条件的条目数。

条目上的 **重读** 可重新获取信息，**移除** 可将条目从本批列表移除。需要登录或补充来源时，点击 **单独处理来源**，在主窗口读取、授权并加入队列；处理后的原批量条目可自行移除。

批量准备列表属于当前窗口会话。点击加入队列后的任务会保存到本机，供再次打开应用时恢复。

## 查找下载历史

切换到 **历史** 页签：

1. 在搜索框输入标题或作者名称。
2. 通过状态列表选择 **全部 / 已完成 / 失败 / 已取消**。
3. 使用 **上一页 / 下一页** 浏览记录，每页最多 30 条。

| 操作 | 作用 |
| --- | --- |
| 打开视频 / 打开音频 | 使用系统关联应用打开该成果 |
| 打开文件夹 | 查看任务目录及其中的文件 |
| 查看来源 | 打开原平台的公开页面 |
| 打开来源网站 | 打开通用网页来源对应的网站入口 |
| 重新下载 | 将来源填回主窗口；读取后选择设置，创建新任务 |
| 重试任务 | 将原任务重新排入队列，复用原任务目录 |
| 删除记录 | 删除这一条历史记录，本地文件继续保留 |
| 清空历史 | 确认后清空已结束任务的记录，本地文件继续保留 |

已生成部分成果的任务也会显示相应的打开按钮。文件被移动后，可以在 Finder 中按原目录或文件名查找。

## 记住常用偏好

拾片自动保存以下设置：

| 设置 | 修改入口 | 生效范围 |
| --- | --- | --- |
| 输出类型 | 主窗口的带声视频、纯音频、视频 + 音频 | 后续读取与新任务 |
| 默认清晰度 | 设置与帮助中的默认清晰度列表 | 后续读取的自动选档 |
| 保存目录 | 主窗口的更换目录 | 后续新任务 |

首次使用的默认组合是 **视频、最高 1080p、系统下载目录**。

**加入队列时，每条任务会保存自己的输出和目录设置。** 后续修改默认值作用于新任务；已有任务可以通过 **编辑设置** 单独调整。

当前视频的 **清晰度** 用于本次选择；需要长期沿用画质策略时，修改 **默认清晰度**。批量条目的格式调整和任务卡片中的编辑也只作用于对应条目。

Chrome 登录态、App 网页会话与偏好分别管理。重新打开 App 后，根据任务提示重新确认访问授权。

## 退出与重启恢复

有活动操作时关闭主窗口，拾片会显示 **继续下载** 和 **保存任务并退出**。

选择保存并退出后，应用收尾当前操作并保存任务。再次打开时：

1. 在 **下载中** 查看保留的等待任务和 **等待恢复** 任务。
2. 点击 **继续队列**。
3. 拾片检查来源、保存位置和已有文件，按顺序恢复可执行任务。
4. 需要补充信息的任务保留在列表中，按任务提示处理。

已有媒体和下载文件会参与复用检查，具体续传取决于来源与工具支持。新下载、整理、合并和校验分别显示阶段进度。

### 重新准备来源

任务需要登录、完整分享链接或新的播放来源时：

1. 点击任务卡片中的 **重新准备来源**。
2. 在主窗口确认正在处理的任务；根据提示补充原视频的完整分享链接，或完成网页登录。
3. 重新读取该视频及对应条目，选择可用输出和清晰度。
4. 点击 **更新任务来源**。
5. 队列处于暂停状态时，点击 **继续队列**。

该操作继续关联原任务。点击 **改为新任务**，则按普通添加流程创建新的保存任务。

## 登录与访问验证

### 在 App 内网页登录

适用于 **抖音、Vimeo 和 X**：

1. 在主窗口粘贴目标视频链接，展开 **登录与访问**，点击 **打开网页登录**。
2. 在打开的页面中完成登录或页面验证，确认目标视频可以播放。
3. 点击登录窗口工具栏的 **使用此会话**。
4. 回到主窗口，点击 **使用网页会话读取**；若显示播放来源按钮，也可以选择对应来源读取。
5. 核对输出与画质，再加入队列。

登录窗口提供 **打开登录页**、**回到目标视频** 和 **返回拾片** 等操作。关闭登录窗口后，已授权会话在本次 App 会话内继续可用。

每个平台使用独立临时会话。同平台多个任务可以复用登录环境，任务分别保留自己的来源和音视频配对。点击 **清除网页会话** 后，该平台的相关任务转入待授权状态；其他可运行任务继续处理。

### 使用本地 Chrome 登录态

对于支持该方式的平台：

1. 在本机 Chrome 默认配置中登录对应平台，并确认视频可播放。
2. 在拾片中展开 **登录与访问**，勾选 **使用本地 Chrome 登录态**，再点击 **读取视频**；访问提示中也可能提供 **使用 Chrome 登录态重新读取**。
3. 按 macOS 提示由本人完成文件访问或钥匙串授权。
4. 核对读取结果后加入队列。

更换输入链接会重置输入区域的 Chrome 开关。已经加入队列的任务保留自己的访问方式；跨启动恢复时按任务提示重新确认。

系统权限需要处理时，可查看 **系统设置 → 隐私与安全 → 文件与文件夹 → 拾片 → Google Chrome**。平台账号、密码与系统授权均由本人在相应页面完成。

## 平台与链接说明

| 来源 | 链接与条目选择 |
| --- | --- |
| YouTube | 使用单条视频、Shorts 等视频链接，按读取结果选择格式 |
| B站 | 链接中的 `p` 参数指定分P；普通视频链接默认第一P |
| 抖音 | 支持视频链接与分享短链接；可通过 App 网页登录准备访问 |
| 小红书 | 使用平台“分享 → 复制链接”得到的完整链接或分享文案，保留分享参数 |
| X | 视频链接中的序号用于选择帖子内的视频；支持 App 网页会话 |
| TikTok | 支持视频页面和已接入的分享短链接 |
| Vimeo | 使用视频链接，私有分享内容保留完整分享参数；可通过 App 网页会话验证访问 |
| 微博 | 帖子包含多个视频时选择对应条目 |
| 公共网页 / MP4 / HLS / DASH | 使用可公开访问的 HTTPS 地址，按读取结果选择视频条目和格式 |

平台要求登录或验证时，使用对应授权入口。内容包含版权保护时，使用平台提供的官方播放或离线方式。

## 保存位置与本地资料

媒体文件保存在所选目录中的独立任务文件夹，文件名通常包含标题与内容标识。视频采用 H.264，音频采用 AAC，分别封装为 MP4 和 M4A。

任务文件夹内可能存在 `.work`、`.work-2` 等工作目录，用于下载、转换与恢复。文件整理时可先在 Finder 中查看成果；保留工作目录有助于原任务恢复，确认成果完整且结束该任务的恢复需求后，可自行清理这些工作文件。

任务、历史和偏好由应用保存在用户数据目录；删除历史记录和清理磁盘文件是两个独立操作。

## 常见提示与处理

| 提示或现象 | 操作 |
| --- | --- |
| 等待下载 / 等待恢复 | 查看队列控制按钮，点击继续队列 |
| 需要处理 / 等待网页授权 | 按任务提示重新准备来源，完成后更新任务来源 |
| 请选择可用清晰度 | 在当前视频的清晰度列表中选择可用档位；原始画质按提示确认 |
| 批量按钮显示可加入数量较少 | 检查各条目的输出能力、清晰度、视频条目与原始画质确认 |
| 播放来源过期 | 回到目标网页播放视频，再选择识别到的来源 |
| 保存位置需要重新确认 | 通过更换目录选择可写入的位置，并按任务情况编辑等待任务或重新下载 |
| 磁盘空间提示 | 释放保存磁盘的空间，再继续队列 |
| 工具异常 | 打开设置与帮助，检查工具路径和状态，准备好工具后重新检测 |
| 文件位置已变化 | 按任务卡片中的提示查看文件位置；成品文件移走时，可点击打开任务文件夹核对成果 |
| 任务保存需要恢复 / 数据需要检查 | 保留应用数据文件，核对磁盘空间与目录权限；向维护者提供界面提示、应用版本和操作步骤 |
| 下载后进入合并、转换或验证 | 等待当前处理阶段完成；较长视频的完整媒体扫描需要相应时间 |

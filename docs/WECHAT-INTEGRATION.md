# 视频号分享链接集成

目标：在拾片内完成视频号分享链接解析、单条及批量任务、MP4/M4A 输出。
分支：`codex/wechat-channels`；基线：`8254659`。
入口：`https://weixin.qq.com/sph/...` 分享链接及分享文案。
登录：用户在独立元宝窗口完成登录并授权，使用当前 App 内存会话。
解析：元宝解析接口 → 视频号公开预览接口 → 腾讯媒体来源。
下载：主进程通过内存描述符向现有下载器提供媒体描述。
队列：保存公开分享链接与任务信息，执行时刷新媒体地址。
恢复：会话过期进入等待授权；清除会话撤销对应任务；重启恢复沿用现有授权流程。
输出：复用 FFmpeg 格式整理与 ffprobe 完整包、时长和轨道校验。
范围：已发布普通视频；媒体类型与保护标志在解析阶段校验。
许可：协议适配参考来源与许可证登记在 THIRD_PARTY_NOTICES.md。
验收：用户负责真实账号及线上视频验收，自动验证使用隔离会话和合成媒体。
证据：`evidence/wechat-integration-20261030/`，记录命令、退出码和代码输入摘要。

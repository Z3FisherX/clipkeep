# 拾片 0.7.0

微信视频号分享链接现可接入拾片的下载队列。用户在 App 的独立元宝窗口登录并授权后，可读取单条或批量分享链接，选择 MP4、M4A 或双输出。

- 自动识别视频号链接和分享文案，读取标题、作者与可用画质。
- 下载前刷新媒体地址；取消、重试和历史记录沿用拾片队列。
- 登录信息保留在独立内存会话；关闭登录窗口继续使用，清除会话或退出 App 结束授权。
- 会话过期与重启恢复通过原任务重新准备来源。
- 成品经过 FFmpeg 整理与 ffprobe 完整包、轨道校验。

本版本自动验收包含协议边界、会话隔离、队列恢复、真实本地媒体和 Electron 操作。真实账号与线上视频由用户手动验收。

首次操作与恢复步骤见[用户指南](../USER-GUIDE.md#微信视频号)。协议适配的 MIT + Commons Clause 条款见[第三方说明](../../THIRD_PARTY_NOTICES.md)。

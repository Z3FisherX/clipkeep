# 拾片 0.6.1 预发布

[下载 App 压缩包](https://github.com/Z3FisherX/clipkeep/releases/download/v0.6.1/Clipkeep-0.6.1-mac-arm64.zip) · [下载校验文件](https://github.com/Z3FisherX/clipkeep/releases/download/v0.6.1/SHA256SUMS.txt) · [源码仓库](https://github.com/Z3FisherX/clipkeep)

适用 Apple Silicon Mac。应用声明最低 macOS 13.0；当前本地实际验收环境为 macOS 27.0.1，自动检查配置为 macOS 15。

## 更新

- 原始画质任务保留已确认档位，可继续编辑输出及画质策略。
- 处理带额外轨道的 OGV 来源，保留必要音视频校验。
- 删除历史末页记录后自动回到有效页码。
- 成果文件移动后，在对应任务内提供定位与恢复提示。
- 固定双栏、常驻下载按钮，批量和设置使用独立面板。
- 更新 Electron 44.9.3、Zod 4.6.6 与相关下载依赖的安全修复版本。
- 支持发现 Homebrew 独立安装的 Node.js 24。

## 安装

解压后进入 `拾片-darwin-arm64` 文件夹，将 `拾片.app` 拖入“应用程序”。本机准备 FFmpeg、ffprobe 和 Node.js 24；App 附带 yt-dlp 2026.08.19。使用 Homebrew 时可执行 `brew install ffmpeg node@24`。

首次启动按 macOS 来源确认提示操作。当前包采用本地 ad-hoc 签名。打开底部设置检查工具状态后，粘贴有权下载的公开链接，选择格式和保存目录并开始下载。

## 校验和许可

将 ZIP 与 `SHA256SUMS.txt` 下载到同一文件夹，在该文件夹运行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

输出 `Clipkeep-0.6.1-mac-arm64.zip: OK` 表示文件校验通过。ZIP 保留 Electron/Chromium 声明，App 的 `Contents/Resources/third-party/` 保存项目及其他组件原始许可。
